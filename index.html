pyfolio is a Python library for performance and risk analysis of financial portfolios that works well with the Zipline open source backtesting library.

Maintenance and new development#

We continue to maintain Pyfolio Reloaded for bug, security and compatibility fixes. Our new feature development focuses on the current ML4T libraries, including ML4T Diagnostic. For new projects, we recommend evaluating Diagnostic through its migration guide, which includes a runnable portfolio example and explains differences between the workflows. See the Diagnostic documentation for its supported APIs.

Installation#

Pyfolio 0.10.0 and this source version support Python 3.11-3.15. Python 3.9 and 3.10 are retired. Existing release artifacts retain their original Python requirements. See the Python support schedule.

This source version supports pandas 3.0 and 3.1 on Python 3.11-3.15, alongside the existing pandas 1.5/2.x combinations where supported by the interpreter. Pandas 3.2 and later are not yet qualified. Published 0.10.0 permits pandas 3.0 only on Python 3.15.

Pandas 3.1 requires NumPy 2.0.2 or newer on Python 3.11-3.13. The dependency resolver applies its requirements alongside the Python-specific floors below.

When sharing an environment with Zipline, its dependency constraints also apply. Zipline Reloaded 3.2.0 requires pandas below 3.0; use a compatible pandas 2.x environment for that integration. Pyfolio itself does not require Zipline.

Python 3.14 requires pandas 2.3.3 or newer and NumPy 2.3.3 or newer. Python 3.15 requires pandas 3.0.6 and NumPy 2.5.4 or newer; pandas 2.3.3 crashes during date-range construction in the stable CPython 3.15 Linux qualification. The dependency markers select the appropriate combination. Bottleneck currently builds from source on Python 3.15, so that installation needs a C compiler.

To install a published Pyfolio release into a supported environment, run:

pip install pyfolio-reloaded

The Conda channel contains historical releases:

conda install -c ml4t pyfolio-reloaded

The frozen Conda 0.9.4 recipe and existing channel artifacts are preserved. That recipe does not build this source version, and its publishing workflow is retired.

Development#

Clone this repository, then create an isolated environment and install the declared extras:

uv venv --python 3.11
uv pip install -e '.[test,docs,dev]'
uv run pre-commit install

Usage#

A good way to get started is to run the pyfolio examples in a Jupyter notebook. To do this, you first want to start a Jupyter notebook server:

jupyter notebook

From the notebook list page, navigate to the pyfolio examples directory and open a notebook. Execute the code in a notebook cell by clicking on it and hitting Shift+Enter.
